# Hello MCP

A simple MCP server that provides three tools:

- `get_greeting(name)`: returns a greeting for a student.
- `add_numbers(a, b)`: returns the sum of two integers.
- `multiply_numbers(a, b)`: returns the product of two integers.

## Run

Run the server with Python in an environment that has the project's MCP server dependency installed:

```powershell
python server.py
```
